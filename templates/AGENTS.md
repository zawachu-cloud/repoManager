## 目錄結構

```

├── AGENTS.md          # 本檔:精簡規範,指向 docs/
```

## 慣例

- **語言**:文件與 UI 文案用繁體中文;程式碼識別符用英文。
- **機密**:真實金鑰只放 `.env`(已 gitignore);版控只放 `.env.example`。
- **暫存**:草稿/實驗放 `tmp/`,不進版控。
- **文件分層**:AGENTS.md 只放摘要,細節放 `docs/`,避免兩處重複。
- **提交**:小步提交,訊息用祈使句;改功能後同步更新 `docs/`。

## 給 AI 代理的工作準則

- 動工前先讀 `docs/` 對應文件;修改功能後同步更新相關文件。
- 破壞性/難復原動作(drop/truncate、force push、`reset --hard`、`rm -rf`)先向老闆確認。
- 收尾(close session)依 repoManager `docs/repo-standard.md` §3:未辦事項 → git 乾淨 → 文件與程式一致。
